# 此刻收音机

一个不催促、不评分的情绪记录网页。原生 HTML、CSS、JavaScript，无运行时依赖。

## 启动

需要 Node.js 20 或更新版本。在仓库目录运行 `npm run dev`，默认端口 3000，可通过 `PORT` 覆盖。

## 使用

拖动旋钮或使用方向键选择 12 档感受，按住按钮约 1.9 秒生成票根。支持本地保存、票根回看、重新选择、系统文字分享或文本导出、可关闭声音、键盘操作与减弱动态效果。辅助技术可直接激活收取按钮。

记录仅存于当前浏览器，不上传服务器。此原型不提供跨端同步、系统小组件、自由文本危机识别或医疗服务。求助入口无需登录。在线字体不可用时自动使用系统字体。
